  1. Before the computer

    Water, DNA and a sequencing machine

    Every living thing sheds DNA into the water around it — skin cells, mucus, waste, whole tiny bodies. A single bottle of lake water therefore carries a genetic trace of the community living there. This approach is called environmental DNA (eDNA).

    Deepor Beel lies right beside Guwahati’s municipal solid-waste dumping ground, while Chandubi Beel has no comparable pressure — so comparing the two shows what that pressure does to the life in the water. No water chemistry was measured; instead, the organisms themselves serve as indicators of water condition (Steps 9 and 11).

    Water was collected on 29 March 2026 — Chandubi Beel at 25.881015° N, 91.422898° E and Deepor Beel at 26.10953° N, 91.70818° E — the DNA extracted, and two short barcode genes copied millions of times and read by an Illumina MiSeq sequencer at Eurofins Genomics:

    18S rRNA

    A barcode shared by almost all complex life. It catches microscopic algae, protists and fungi as well as small animals — the base of the food web.

    COI

    The classic “animal barcode”. It catches zooplankton — rotifers, water fleas, copepods, mites and insect larvae.

    The machine returns its output as text files of DNA letters (A, C, G, T). Everything below is about turning those raw files into a clean, trustworthy list of the distinct DNA signatures present in each lake.

# Step 1 — Raw read QC: checksum verification, FastQC + MultiQC, per-file read stats,
# and DADA2 quality profiles. Inputs: NEW/<marker>/<site>/*.fastq.gz
set -euo pipefail
cd "$(dirname "$0")/.."

OUT=results/01_qc
mkdir -p "$OUT" work/01_fastqc docs/img

# 1a. MD5 verification against the vendor checksum files
: > "$OUT/md5_check.tsv"
for m in 18S COI; do
  while read -r hash file; do
    path=$(ls NEW/"$m"/*/"$file")
    got=$(md5sum < "$path" | cut -d' ' -f1)
    status=$([ "$got" = "$hash" ] && echo OK || echo FAIL)
    printf '%s\t%s\t%s\n' "$m" "$path" "$status" >> "$OUT/md5_check.tsv"
  done < NEW/"$m"/MD5SUM_Raw.txt
done

# 1b. FastQC on every raw file, summarised with MultiQC
find NEW -name '*.fastq.gz' -print0 | xargs -0 fastqc -q -t 8 --outdir work/01_fastqc
multiqc -q -f -o "$OUT/multiqc" -n multiqc_raw.html work/01_fastqc

# 1c. Read count / length / GC / mean quality per file
printf 'marker\tsite\tsample\tread\treads\tmean_len\tgc_pct\tmean_q\n' > "$OUT/read_stats.tsv"
for f in NEW/*/*/*.fastq.gz; do
  marker=$(echo "$f" | cut -d/ -f2); site=$(echo "$f" | cut -d/ -f3)
  base=$(basename "$f" .fastq.gz); sample=${base%_R*}; read=${base##*_}
  zcat "$f" | awk -v m="$marker" -v s="$site" -v sm="$sample" -v r="$read" '
    BEGIN { for (i = 33; i < 127; i++) ord[sprintf("%c", i)] = i - 33 }
    NR % 4 == 2 { n++; len += length($0); gc += gsub(/[GCgc]/, "") }
    NR % 4 == 0 { for (i = 1; i <= length($0); i++) q += ord[substr($0, i, 1)]; qn += length($0) }
    END { printf "%s\t%s\t%s\t%s\t%d\t%.1f\t%.1f\t%.1f\n", m, s, sm, r, n, len/n, 100*gc/len, q/qn }' \

  3. Step 2

    Removing the copying labels

    In plain wordsTo copy a barcode gene, the lab uses short “starter” pieces of DNA called primers — think of them as address labels stuck to each end. They are not part of the organism’s DNA, so they are cut off. Any fragment missing its labels was copied by mistake and is thrown away.

    Nearly nine in ten fragments carried both labels exactly where expected — a sign the lab work went well. The primers were identified by reading the data itself, not taken on trust.

    #!/usr/bin/env bash
# Step 2 — Primer removal with Cutadapt.
# Each read must start with its primer (anchored 5'); pairs where either primer is
# missing are discarded. If a read runs through into the opposite primer, that
# (reverse-complemented) primer and everything after it is trimmed too.
#   18S V4 : E572F  CYGCGGTAATTCCAGCTC     / E1009R   AYGGTATCTRWTCRTCTTYG   (Comeau et al. 2011)
#   COI    : mlCOIintF GGWACWGGWTGAACWGTWTAYCCYCC / jgHCO2198 TAIACYTCIGGRTGICCRAARAAYCA (Leray et al. 2013; I -> N)
set -euo pipefail
cd "$(dirname "$0")/.."

OUT=results/02_primer_removal
mkdir -p "$OUT" work/02_trimmed

revcomp() { echo "$1" | rev | tr ACGTRYKMBVDHN TGCAYRMKVBHDN; }

declare -A FWD=( [18S]=CYGCGGTAATTCCAGCTC [COI]=GGWACWGGWTGAACWGTWTAYCCYCC )
declare -A REV=( [18S]=AYGGTATCTRWTCRTCTTYG [COI]=TANACYTCNGGRTGNCCRAARAAYCA )

printf 'marker\tsample\tpairs_in\tpairs_with_both_primers\tpct_kept\n' > "$OUT/cutadapt_summary.tsv"
for m in 18S COI; do
  F=${FWD[$m]}; R=${REV[$m]}
  mkdir -p "work/02_trimmed/$m"
  for r1 in NEW/"$m"/*/*_R1.fastq.gz; do
    s=$(basename "$r1" _R1.fastq.gz); r2=${r1/_R1/_R2}
    cutadapt -j 8 --discard-untrimmed -e 0.15 --minimum-length 50 \
      -g "^${F};required...$(revcomp "$R");optional" -G "^${R};required...$(revcomp "$F");optional" \
      --json "$OUT/${m}_${s}.cutadapt.json" \
      -o "work/02_trimmed/$m/${s}_R1.fastq.gz" -p "work/02_trimmed/$m/${s}_R2.fastq.gz" \
      "$r1" "$r2" > "$OUT/${m}_${s}.cutadapt.log"
    python3 - "$OUT/${m}_${s}.cutadapt.json" "$m" "$s" >> "$OUT/cutadapt_summary.tsv" <<'PY'
import json, sys
j = json.load(open(sys.argv[1]))["read_counts"]
print(f"{sys.argv[2]}\t{sys.argv[3]}\t{j['input']}\t{j['output']}\t{100*j['output']/j['input']:.1f}")
PY
  done
done

# Post-trim length distribution (input to choosing DADA2 truncation lengths)
printf 'marker\tsample\tread\tlength\tcount\n' > "$OUT/trimmed_lengths.tsv"
for f in work/02_trimmed/*/*.fastq.gz; do
  m=$(basename "$(dirname "$f")"); b=$(basename "$f" .fastq.gz)
  zcat "$f" | awk -v m="$m" -v s="${b%_R*}" -v r="${b##*_}" \
    'NR%4==2{c[length($0)]++} END{for(l in c) printf "%s\t%s\t%s\t%d\t%d\n", m, s, r, l, c[l]}' \
    >> "$OUT/trimmed_lengths.tsv"
done

  4. Step 3

    Separating real DNA from typos

    In plain wordsSequencers make occasional typos. If you counted every slightly different spelling as a new organism you would invent thousands of species that don’t exist. This step learns the machine’s typo habits from the data itself, then decides which sequences are real and which are just misspellings of them.

    What survives is a list of ASVs (amplicon sequence variants) — each one an exact, unique DNA signature, roughly “one distinct kind of organism”. The two reads of each fragment are then joined into one full sequence, and chimeras — artificial sequences glued together from two different organisms during copying — are removed.

    Importantly, both lakes were processed together, so the same organism gets the same signature in both lakes and they can be compared fairly.

  5. Step 4

    Weeding out fakes

    In plain wordsThe COI barcode is a recipe for a protein. A genuine recipe reads like a sentence with no “STOP” in the middle. Sequences that contain a stop, or whose length breaks the three-letter rhythm of the code, are broken copies (old “ghost” genes or errors) and are removed. For 18S, sequences far too short or too long to be the real barcode are removed.

    Script scripts/04_asv_curation.R
    # Step 4 — ASV curation.
#  COI : a real COI ASV is protein-coding. Keep ASVs whose length differs from the 313 bp
#        Leray fragment by whole codons (±10 codons) AND translate with no stop codon
#        under the invertebrate mitochondrial code (NCBI table 5). Others are likely
#        NUMTs / pseudogenes or artefacts.
#  18S : keep ASVs within the expected V4 (E572F–E1009R) length window, 350–480 bp.
suppressPackageStartupMessages({ library(Biostrings); library(data.table); library(ggplot2) })

out <- "results/04_curation"
dir.create(out, recursive = TRUE, showWarnings = FALSE)
read_asv <- function(m) fread(file.path("results/03_dada2", m, "asv_table.tsv"))

# ---- COI ----
coi <- read_asv("COI")
dna <- DNAStringSet(coi$sequence)
code5 <- getGeneticCode("5")
stops_in_frame <- sapply(1:3, function(f)
  vcountPattern("*", suppressWarnings(translate(subseq(dna, f), genetic.code = code5,
                                                if.fuzzy.codon = "X"))))
# The coding frame is the one that is stop-free for the most reads
frame <- which.max(colSums((stops_in_frame == 0) * (coi$W1 + coi$W2)))
coi[, `:=`(stops = stops_in_frame[, frame],
           codon_ok = abs(length - 313) %% 3 == 0 & abs(length - 313) <= 30)]
coi[, keep := codon_ok & stops == 0]
coi[, reason := fifelse(keep, "kept", fifelse(!codon_ok, "length not codon-compatible", "stop codon in frame"))]

# ---- 18S ----
s18 <- read_asv("18S")
s18[, keep := length >= 350 & length <= 480]
s18[, reason := fifelse(keep, "kept", "outside 350–480 bp")]

# ---- Write curated tables + summary ----
summ <- rbindlist(lapply(list(COI = coi, `18S` = s18), function(d)
  d[, .(asvs = .N, W1_reads = sum(W1), W2_reads = sum(W2)), by = reason]), idcol = "marker")
fwrite(summ, file.path(out, "curation_summary.tsv"), sep = "\t")

cat(sprintf("COI coding frame: +%d\n", frame), file = file.path(out, "COI_frame.txt"))

    In plain wordsEach signature is still just a string of DNA letters. A name is accepted only when the match is both confident and close enough: a species name, for example, needs the sequence to be at least 97–99% identical to a known one. If the match is weaker, we only claim a broader group (a family, or just “a rotifer”).

# Step 6 — Taxonomic assignment of curated ASVs with VSEARCH.
#  (a) SINTAX: k-mer classifier with bootstrap confidence per rank (cutoff applied in R).
#  (b) Global alignment to the same reference: % identity of the closest reference sequence,
#      used to decide whether genus/species names are close enough to trust.
# References (downloaded to work/refs, git-ignored):
#   18S : PR2 v5.1.1 SSU, UTAX/SINTAX format
#         https://github.com/pr2database/pr2database/releases/tag/v5.1.1
#   COI : Eukaryote CO1 Reference Set v5.1.0 (Porter & Hajibabaei), SINTAX format
#         https://github.com/terrimporter/CO1Classifier/releases/tag/SINTAX-COI-v5.1.0-ref
set -euo pipefail
cd "$(dirname "$0")/.."

REFS=work/refs
OUT=results/06_taxonomy

  curl -sL -o "$REFS/pr2_5.1.1_UTAX.fasta.gz" \
    https://github.com/pr2database/pr2database/releases/download/v5.1.1/pr2_version_5.1.1_SSU_UTAX.fasta.gz
fi
if [ ! -s "$REFS/COIv5.1.0_sintax.fasta" ]; then
  curl -sL -o "$REFS/coi.zip" \
    https://github.com/terrimporter/CO1Classifier/releases/download/SINTAX-COI-v5.1.0-ref/SINTAX_COIv5.1.0_ref.zip
  # sequences are distributed in lower case, which VSEARCH treats as masked -> upper-case them
  unzip -p "$REFS/coi.zip" training/sintax.fasta | awk '/^>/ {print; next} {print toupper($0)}' \
    > "$REFS/COIv5.1.0_sintax.fasta" && rm "$REFS/coi.zip"
fi

for m in 18S COI; do
  q=results/04_curation/${m}_asv_seqs_curated.fasta
  # (a) classifier, 100 bootstrap subsamples, both strands
  vsearch --sintax "$q" --db "${DB[$m]}" --strand both --sintax_random --randseed 2026 \
    --tabbedout "$OUT/${m}_sintax.tsv" --threads 16 --quiet

  vsearch --usearch_global "$q" --db "${DB[$m]}" --id 0.70 --strand both \
    --maxaccepts 20 --maxrejects 500 --top_hits_only --output_no_hits \
    --userout "$OUT/${m}_tophit.tsv" --userfields query+target+id+alnlen \
    --threads 16 --quiet
done

    # Step 6 — Turn raw SINTAX + top-hit output into a conservative taxonomy table.
# A rank is accepted only if BOTH
#   (1) SINTAX bootstrap confidence >= 0.80, and
#   (2) the closest reference sequence is similar enough for that rank:
#         COI : species >= 97 %, genus >= 95 %, family >= 90 %, order >= 85 %
#         18S : species >= 99 %, genus >= 97 %, family >= 95 %
# Ranks are accepted top-down; once one fails, all lower ranks are left unassigned.
# PR2 placeholder names (e.g. "Dinophyceae_X", "Enoplea_XX_sp.") are left blank at their
# own rank but do not stop lower ranks (e.g. order "Sphaeropleales_X" -> genus Desmodesmus).
suppressPackageStartupMessages({ library(data.table); library(ggplot2) })

out <- "results/06_taxonomy"
CONF <- 0.80
ranks <- list(
  COI = c(d = "Domain", k = "Kingdom", p = "Phylum", c = "Class", o = "Order",
          f = "Family", g = "Genus", s = "Species"),
  `18S` = c(k = "Domain", d = "Supergroup", p = "Division", c = "Class", o = "Order",
            f = "Family", g = "Genus", s = "Species"))

               `18S` = c(Family = 95, Genus = 97, Species = 99))
site_of <- c(W1 = "Chandubi (W1)", W2 = "Deepor Beel (W2)")

parse_sintax <- function(m) {
  s <- fread(file.path(out, sprintf("%s_sintax.tsv", m)), header = FALSE, sep = "\t", quote = "",
             fill = TRUE, col.names = c("asv", "tax", "strand"))[, 1:2]
  r <- ranks[[m]]
  rbindlist(lapply(seq_len(nrow(s)), function(i) {
    parts <- if (is.na(s$tax[i]) || s$tax[i] == "") character() else strsplit(s$tax[i], ",")[[1]]
    d <- data.table(asv = s$asv[i], letter = sub(":.*", "", parts),
                    name = sub("^.:(.*)\\(.*$", "\\1", parts),
                    conf = as.numeric(sub(".*\\((.*)\\)$", "\\1", parts)))
    d[, rank := r[letter]][]
  }), fill = TRUE)
}

summarise_marker <- function(m) {
  r <- unname(ranks[[m]])
  counts <- fread(sprintf("results/04_curation/%s_asv_table_curated.tsv", m))[, .(asv, W1, W2, length)]
  long <- parse_sintax(m)

  hit <- fread(file.path(out, sprintf("%s_tophit.tsv", m)), header = FALSE, sep = "\t", quote = "",
               col.names = c("asv", "target", "identity", "alnlen"))
  hit <- hit[target != "*"][order(asv, -identity)][, .SD[1], by = asv]
  hit[, best_match := gsub("_", " ", sub(".*s:", "", target))]

  # Accept ranks top-down
  long <- merge(long, hit[, .(asv, identity)], by = "asv", all.x = TRUE)
  long[, need := min_id[[m]][rank]][is.na(need), need := 0]
  # PR2 joins division and subdivision ("Chlorophyta-Chlorophyta_X"): keep the division part
  long[, name := sub("-[^-]*_X+$", "", name)]
  long[, placeholder := grepl("(_X+|_sp\\.)$", name) | grepl("^undef_", name)]
  long[, ok := conf >= CONF & !is.na(identity) & identity >= need]
  long[, rank := factor(rank, levels = r)]
  setorder(long, asv, rank)
  long[, ok := cumprod(ok) == 1, by = asv]

  # Placeholders are left blank at their own rank but do not block the ranks below
  wide <- dcast(long[ok == TRUE & !placeholder], asv ~ rank, value.var = "name")
  for (x in r) if (!x %in% names(wide)) wide[, (x) := NA_character_]
  conf_wide <- dcast(long, asv ~ rank, value.var = "conf")
  setnames(conf_wide, setdiff(names(conf_wide), "asv"), paste0("conf_", setdiff(names(conf_wide), "asv")))

  tax <- Reduce(function(a, b) merge(a, b, by = "asv", all.x = TRUE),
                list(counts, wide[, c("asv", r), with = FALSE], conf_wide,
                     hit[, .(asv, identity, best_match)]))
  tax[, deepest := apply(.SD, 1, function(v) { k <- which(!is.na(v)); if (length(k)) r[max(k)] else "Unassigned" }),
      .SDcols = r]
  tax[, label := apply(.SD, 1, function(v) { k <- which(!is.na(v)); if (length(k)) v[max(k)] else "Unassigned" }),
      .SDcols = r]
  tax[, label := gsub("_", " ", label)]
  setorder(tax, -W1)
  fwrite(tax[order(asv)], file.path(out, sprintf("%s_taxonomy.tsv", m)), sep = "\t")
  tax[, marker := m][]
}

"""Step 6b helper — BLAST a FASTA file against NCBI core_nt through the NCBI BLAST
URL API (submit, poll, fetch). Writes one tab-separated row per hit:
qseqid, accession, pident, align_len, qcov, evalue, taxid, sciname, kingdom, phylum, class.

import re
import sys
import time
import urllib.parse
import urllib.request

URL = "https://blast.ncbi.nlm.nih.gov/Blast.cgi"
query, out = sys.argv[1], sys.argv[2]
max_hits = int(sys.argv[3]) if len(sys.argv) > 3 else 5
sensitive = "--sensitive" in sys.argv


def call(params, data=False):
    enc = urllib.parse.urlencode(params).encode()
    req = urllib.request.Request(URL, data=enc if data else None,
                                 headers={"User-Agent": "Sahil_Metagenome/1.0 (amplicon taxonomy)"})
    if not data:
        req.full_url = URL + "?" + enc.decode()
    with urllib.request.urlopen(req, timeout=120) as r:
        return r.read()


fasta = open(query).read()
qlen = {m.group(1): len(m.group(2).replace("\n", ""))
        for m in re.finditer(r">(\S+)[^\n]*\n([^>]*)", fasta)}

if sensitive:
    mode = {"PROGRAM": "blastn", "DATABASE": "core_nt", "MEGABLAST": "off", "WORD_SIZE": 11}
else:
    mode = {"PROGRAM": "blastn", "DATABASE": "core_nt", "MEGABLAST": "on"}
resp = call({"CMD": "Put", **mode,
             "QUERY": fasta, "HITLIST_SIZE": max_hits, "EXPECT": "1e-20",
             "EMAIL": "", "TOOL": "Sahil_Metagenome"}, data=True).decode()
rid = re.search(r"RID = (\S+)", resp).group(1)
wait = int(re.search(r"RTOE = (\d+)", resp).group(1))
print(f"RID {rid}, estimated {wait}s", file=sys.stderr)
time.sleep(max(wait, 30))
deadline = time.time() + 90 * 60  # give up after 90 minutes
while True:
    if time.time() > deadline:
        sys.exit(f"BLAST RID {rid} did not finish within 90 minutes")
    status = call({"CMD": "Get", "RID": rid, "FORMAT_OBJECT": "SearchInfo"}).decode()
    s = re.search(r"Status=(\w+)", status).group(1)
    print(f"{time.strftime('%H:%M')} status {s}", file=sys.stderr, flush=True)
    if s == "READY":
        break
    if s in ("FAILED", "UNKNOWN"):
        sys.exit(f"BLAST {s} for RID {rid}")
    time.sleep(60)

raw = call({"CMD": "Get", "RID": rid, "FORMAT_TYPE": "JSON2_S"})
doc = json.loads(raw)
rows = []
for rep in doc["BlastOutput2"]:
    search = rep["report"]["results"]["search"]
    q = search["query_title"].split()[0]
    for hit in search.get("hits", []):
        d = hit["description"][0]
        hsp = hit["hsps"][0]
        rows.append([q, d.get("accession", ""), round(100 * hsp["identity"] / hsp["align_len"], 2),
                     hsp["align_len"], round(100 * (hsp["query_to"] - hsp["query_from"] + 1) / qlen[q], 1),
                     hsp["evalue"], str(d.get("taxid", "")), d.get("sciname", "")])

# Higher taxonomy (phylum, class) for each hit, from NCBI Taxonomy via E-utilities
lineage = {}
taxids = sorted({r[6] for r in rows if r[6]})
for i in range(0, len(taxids), 100):
    xml = urllib.request.urlopen(
        "https://eutils.ncbi.nlm.nih.gov/entrez/eutils/efetch.fcgi?db=taxonomy&id=" + ",".join(taxids[i:i + 100]),
        timeout=120).read().decode()
    for taxon in re.findall(r"<Taxon>\s*<TaxId>(\d+)</TaxId>(.*?)</LineageEx>", xml, re.S):
        tid, body = taxon
        ranks = dict((r, n) for n, r in re.findall(
            r"<ScientificName>([^<]+)</ScientificName>\s*<Rank>([^<]+)</Rank>", body))
        lineage[tid] = (ranks.get("kingdom", ranks.get("superkingdom", "")), ranks.get("phylum", ""),
                        ranks.get("class", ""))
    time.sleep(0.5)

with open(out, "w") as fh:
    for r in rows:
        fh.write("\t".join(map(str, r + list(lineage.get(r[6], ("", "", ""))))) + "\n")
print(f"wrote {out}", file=sys.stderr)

    How diverse is each lake?

    In plain wordsDiversity has two sides: how many kinds there are, and how evenly they are spread. A lake with 100 kinds where one makes up 90% of everything is less diverse in practice than one with 100 equally common kinds. To compare fairly, both lakes are first cut down to the same number of reads — like comparing two birdwatchers who each watched for exactly one hour.

    We report diversity as an effective number of types: “this community is as diverse as one with N equally common types”. Counting every type gives the largest number; counting only the common ones gives a smaller one.

    Reading the lakes’ ecology

    In plain wordsA list of names becomes useful when we ask what those organisms do: who makes food from sunlight (algae), who eats (protozoa, animals), who recycles or infects (fungi, water moulds, parasites). Some organisms are also well-known indicators — their presence hints at how nutrient-rich or polluted water is.

    Who does what (18S)

    In Chandubi, about 29% of 18S reads come from algae — green algae and diatoms above all — and another 24% from free-living protozoa: a community built on producers and grazers. In Deepor, algae make up 27% (mostly desmids), while fungi (24%) and water moulds (9%) take a much larger share — a community leaning towards decomposition and parasitism, as expected where dead plant material is plentiful.

    Zooplankton groups (COI, including the GenBank look-ups)

    Rotifers make up about 60% (Chandubi) and 65% (Deepor) of COI reads. Crustaceans are scarce in this barcode — copepods, ostracods and insects together are under 1%. About a fifth of reads remain unknown, the largest part being the single unidentified organism found in Step 7.

    The main players

    Two barcodes see different animals

    Of the animal genera named, 14 were found only by 18S (flatworms, gastrotrichs, oligochaete worms, copepods Eucyclops and Microcyclops), 5 only by COI (the main rotifers Brachionus, Keratella, Polyarthra, Asplanchna, and the mayfly Cloeon), and just 1 by both (Mesocyclops). Using two barcodes roughly doubled the animal list — the main argument for a multi-marker design.

    Indicator organisms

    Several organisms that ecologists use as water-quality signals were found. The picture is mixed rather than simple:

    • Nutrient-rich signals in both lakes: the rotifers Brachionus and Keratella tropica are abundant everywhere and somewhat more so in Deepor. Chandubi additionally holds diatoms typical of enriched water (Cyclotella meneghiniana, Nitzschia palea, Aulacoseira granulata).
    • Deepor’s desmids (Staurastrum, Cosmarium) are a group often linked to plant-rich, less enriched water — fitting a macrophyte-covered wetland — alongside chytrid parasites of algae.

    These are pointers rather than verdicts; read together they are consistent with nutrient enrichment, strongest at Deepor beside the dumping ground.

  11. Step 10

    A second look at the unknowns — through their proteins

    In plain wordsCOI is a recipe for a protein. Over evolution the DNA “spelling” changes much faster than the protein it makes — many different spellings give the same protein. So two organisms whose DNA looks only 75% alike can still have very similar proteins, which reveals their family ties. We translated the unknown sequences into protein and compared them with 2.2 million known COI proteins.

    22 of 32unknowns that are rotifers
    29% / 25%COI reads they add (Chandubi / Deepor)
    86%best protein match, top unknown

    Most unknowns are rotifers. Their proteins are 89–98% identical to known rotifers such as Trichocerca, Euchlanis, Filinia, Lecane and Brachionus — confirming that the lakes hold many rotifer species whose DNA has never been catalogued. A few others point to mites, an ostracod, a freshwater sponge and an amoeba.

    The most common COI signature remains a mystery. COI_ASV0001’s protein is closest to a nematode (roundworm, 86% identical) but almost as close to brown-algae-like stramenopiles (~81%). The evidence does not settle which group it belongs to — it may be an organism from a group that has barely been sequenced. Isolating and sequencing it (or its full mitochondrial genome) would be needed to name it.

    Script scripts/10_protein_search.sh
    #!/usr/bin/env bash
# Step 10 — Protein-level identification of COI ASVs that have no close DNA match in GenBank
# (best BLASTn identity < 90 %). DNA changes faster than the protein it encodes, so comparing
# translated sequences can still place a sequence in its phylum or class when DNA similarity
# is too low to say anything.
# Reference: the Eukaryote CO1 Reference Set (step 6) translated to protein — each sequence in
# the reading frame with fewest stop codons, invertebrate mitochondrial code (table 5).
# Search: DIAMOND blastx (local; NCBI's online BLASTx queue proved unusable for this run).
set -euo pipefail
cd "$(dirname "$0")/.."

OUT=results/10_protein
REFS=work/refs
mkdir -p "$OUT"

if [ ! -s "$REFS/COIv5.1.0_protein.dmnd" ]; then
  seqkit translate -j 8 -T 5 -f 1,2,3 -w 0 "$REFS/COIv5.1.0_sintax.fasta" 2>/dev/null |
    awk '/^>/ { h = $1; sub(/_frame=[0-9]+$/, "", h); next }
         { n = gsub(/\*/, "X"); if (!(h in best) || n < best[h]) { best[h] = n; seq[h] = $0 } }
         END { for (k in seq) print k "\n" seq[k] }' > "$REFS/COIv5.1.0_protein.faa"
  diamond makedb --in "$REFS/COIv5.1.0_protein.faa" -d "$REFS/COIv5.1.0_protein" --quiet
  rm "$REFS/COIv5.1.0_protein.faa"
fi

# Query: all COI ASVs that were looked up in GenBank and had no >= 90 % DNA match
awk -F'\t' 'NR==1 {for (i=1;i<=NF;i++) h[$i]=i; next}
            ($h["ncbi_identity"]=="" || $h["ncbi_identity"]<90) {print $h["asv"]}' \
  results/06_taxonomy/COI_blast_unknowns_summary.tsv > work/protein_ids.txt
awk 'NR==FNR {want[">" $1]=1; next} /^>/ {keep = ($1 in want)} keep' \
  work/protein_ids.txt results/04_curation/COI_asv_seqs_curated.fasta > work/protein_query.fasta

diamond blastx -q work/protein_query.fasta -d "$REFS/COIv5.1.0_protein" --query-gencode 5 \
  --ultra-sensitive --max-target-seqs 25 --evalue 1e-10 --threads 16 --quiet \
  --outfmt 6 qseqid sseqid pident length qcovhsp evalue bitscore -o "$OUT/COI_protein_hits.tsv"

  12. Step 11

    A rotifer signal of nutrient levels

    In plain wordsRotifers are useful messengers. A classic rule of thumb compares two rotifer genera: Brachionus, which thrives in nutrient-rich water, and Trichocerca, more typical of cleaner water. Dividing the number of Brachionus species by the number of Trichocerca species gives the QB/T index: below 1 suggests nutrient-poor water, 1–2 moderate, above 2 nutrient-rich.

    Few COI sequences can be named to species, so “species” here are clusters of sequences that are at least 97% identical — a standard stand-in for species with this barcode.

    5QB/T Chandubi
    5QB/T Deepor

    Both lakes score well above 2 — a nutrient-rich (eutrophic) signal in both, with about 10 Brachionus clusters against 2 Trichocerca. Treat the exact value as provisional: several genus names come only from distant GenBank matches (80–90%).

  const out = [];
  expand(text).split(/(\*\*[^*]+\*\*|\*[^*]+\*)/).forEach((seg) => {
    if (!seg) return;
    if (seg.startsWith("**")) out.push(new TextRun({ text: seg.slice(2, -2), bold: true, font: FONT, size: SIZE, ...base }));
    else if (seg.startsWith("*")) out.push(new TextRun({ text: seg.slice(1, -1), italics: true, font: FONT, size: SIZE, ...base }));
    else out.push(new TextRun({ text: seg, font: FONT, size: SIZE, ...base }));
  });
  return out;
}

}

const BORDER = { style: BorderStyle.SINGLE, size: 4, color: "000000" };
const NONE = { style: BorderStyle.NONE, size: 0, color: "FFFFFF" };
function TABLE(n, caption, header, rows, widths, note) {
  const total = widths.reduce((a, b) => a + b, 0);
  const cell = (t, i, isHead, last) => new TableCell({
    width: { size: widths[i], type: WidthType.DXA },
    borders: { top: isHead ? BORDER : NONE, bottom: isHead || last ? BORDER : NONE, left: NONE, right: NONE },
    children: [new Paragraph({ children: runs(String(t), { size: 18, bold: isHead }),
      alignment: i === 0 ? AlignmentType.LEFT : AlignmentType.RIGHT })],
    margins: { top: 40, bottom: 40, left: 80, right: 80 },
  });
  const out = [
    new Paragraph({ children: [new TextRun({ text: `Table ${n} `, bold: true, font: FONT, size: SIZE }), ...runs(caption)],
      spacing: { before: 240, after: 80, line: 300 } }),
    new Table({ width: { size: total, type: WidthType.DXA }, columnWidths: widths,
      rows: [new TableRow({ tableHeader: true, children: header.map((t, i) => cell(t, i, true, false)) }),
             ...rows.map((r, j) => new TableRow({ children: r.map((t, i) => cell(t, i, false, j === rows.length - 1)) }))] }),
  ];
  if (note) out.push(new Paragraph({ children: runs(note, { size: 16 }), spacing: { before: 60, after: 240 } }));
  return out;
}

    const init = (x.given || "").split(/[\s.\-]+/).filter(Boolean).map((p) => p[0].toUpperCase() + ".").join(" ");
    return init ? `${x.family}, ${init}` : x.family;
  };

  if (n.length === 1) return n[0];
  if (n.length <= 20) return n.slice(0, -1).join(", ") + ", & " + n[n.length - 1];
  return n.slice(0, 19).join(", ") + ", … " + n[n.length - 1];
}

  15. Step 15

    Does DNA agree with the microscope?

    In plain wordsBefore DNA methods, biologists counted plankton under the microscope. Two such surveys exist for Deepor Beel: rotifers in 2002–03 and algae published in 2020. If DNA is reliable, it should find much of what they found — and may find more.

    Algae — strong agreement on what matters. The microscopists found desmids, above all Cosmarium, to be the richest group in Deepor; DNA independently picks out the same desmids (Staurastrum, Cosmarium, Micrasterias, Closterium, Onychonema…). In all, 16 algal genera are shared, and DNA adds 23 genera the survey did not list. Of the genera seen only under the microscope, 17 are cyanobacteria or euglenoids, which this DNA marker cannot see or sees poorly — cyanobacteria are bacteria and have no 18S gene at all.

    Rotifers — agreement at the genus level. Of the five rotifer genera the microscopists found most important, DNA detects four (Brachionus, Keratella, Asplanchna and, provisionally, Lecane). At species level only Keratella tropica and Polyarthra vulgaris are confirmed, because most rotifer species have no DNA in the reference libraries yet — the same gap seen in Steps 7 and 10.

    The surveys were made in other years and seasons; only presence is compared. Historical water quality from the 2002–03 survey (pH ≈ 6.9, dissolved oxygen ≈ 7 mg/l, conductivity ≈ 98 µS/cm) is context only, not a measurement of these samples.

  16. In summary

    What the data tells us

    Two very different microscopic worlds

    Chandubi is an algae-and-grazer lake: green algae, diatoms, protozoa and rotifers. Deepor is richer in kinds but leans towards fungi, water moulds, desmids and small worms. By 18S the lakes share only 14.5% of their DNA types.

    Rotifers rule the zooplankton

    About 60% (Chandubi) and 65% (Deepor) of animal (COI) reads are rotifers, many of them species not yet in any DNA library. Copepods (Mesocyclops, Eucyclops, Microcyclops) are present; water fleas were not detected.

    Two barcodes are better than one

    Most named animal genera were seen by only one of the two barcodes — neither alone gives the full picture.

    An abundant, unknown organism

    The most common COI signature in both lakes matches nothing on record above ~72% at DNA level; even its protein sits between a nematode and stramenopile algae. It is a genuine unknown — a candidate for closer study.

    A nutrient-rich signal in both lakes

    The rotifer index QB/T is about 5 in Chandubi and 5 in Deepor — well above the threshold of 2 for nutrient-rich water (provisional, as some genus names rest on distant matches).

    Shared zooplankton, different microbes

    By COI, 266 of 345 animal signatures occur in both lakes at similar levels, while the algae, protists and fungi (18S) differ sharply. The sequencing lab has confirmed that the samples were handled correctly, so this is treated as a real pattern: the two floodplain lakes appear to draw on the same regional pool of rotifers, while their microscopic producers and decomposers reflect each lake’s own conditions.

    DNA agrees with the microscope

    In Deepor, DNA recovers the desmids that microscopists found dominant and four of the five key rotifer genera — and adds genera the surveys did not list.

    Cautions

    One water sample per lake: differences describe these two samples and cannot be tested statistically. Read counts reflect DNA, not the number or weight of organisms. Traces of fish and mammal DNA in Deepor are too few to interpret.

Words used on this page

eDNA
Environmental DNA — genetic material organisms leave in water, soil or air.
Barcode gene
A short gene that differs between species, used like a product barcode to tell them apart.
Read
One stretch of DNA letters produced by the sequencer.
Primer
A short starter DNA piece used to copy the barcode; removed before analysis.
ASV
Amplicon sequence variant — one exact, unique DNA signature, roughly one kind of organism.
Chimera
An artificial sequence accidentally stitched from two organisms during copying.
Rarefaction
A check of whether sampling more would have found many more signatures.
Reference library
A collection of DNA sequences from organisms that experts have identified, used to name new sequences.
% identity
How many DNA letters two sequences share; 97–100% usually means the same species.
Effective number of types
Diversity expressed as the number of equally common types that would give the same diversity.
Indicator organism
A species whose presence or abundance signals something about water conditions, such as nutrient level.
BLAST / GenBank
BLAST is a search tool; GenBank is the public archive of nearly all published DNA sequences.
