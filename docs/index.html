  1. Before the computer

    Water, DNA and a sequencing machine

    Every living thing sheds DNA into the water around it — skin cells, mucus, waste, whole tiny bodies. A single bottle of lake water therefore carries a genetic trace of the community living there. This approach is called environmental DNA (eDNA).

    Water was collected from each lake, the DNA extracted, and two short barcode genes copied millions of times and read by an Illumina MiSeq sequencer at Eurofins Genomics:

    18S rRNA

    A barcode shared by almost all complex life. It catches microscopic algae, protists and fungi as well as small animals — the base of the food web.

    COI

    The classic “animal barcode”. It catches zooplankton — rotifers, water fleas, copepods, mites and insect larvae.

    The machine returns its output as text files of DNA letters (A, C, G, T). Everything below is about turning those raw files into a clean, trustworthy list of the distinct DNA signatures present in each lake.

  2. Step 1

    Checking the raw data

    In plain wordsBefore using any data you check it arrived intact and is of good quality — like checking a set of photos for damage and blur before choosing which to print.

    Each file’s digital fingerprint (checksum) was compared to the one supplied by the lab: all eight match, so nothing was corrupted in transfer. Each DNA fragment is read from both ends, giving two 301-letter reads per fragment. The machine’s confidence is high for most of the read but fades towards the end, especially on the second read — so the tail ends will be trimmed in step 3.

# Step 1 — Raw read QC: checksum verification, FastQC + MultiQC, per-file read stats,
# and DADA2 quality profiles. Inputs: NEW/<marker>/<site>/*.fastq.gz

# 1a. MD5 verification against the vendor checksum files
: > "$OUT/md5_check.tsv"
for m in 18S COI; do
  while read -r hash file; do
    path=$(ls NEW/"$m"/*/"$file")
    got=$(md5sum < "$path" | cut -d' ' -f1)
    status=$([ "$got" = "$hash" ] && echo OK || echo FAIL)
    printf '%s\t%s\t%s\n' "$m" "$path" "$status" >> "$OUT/md5_check.tsv"
  done < NEW/"$m"/MD5SUM_Raw.txt
done

# 1b. FastQC on every raw file, summarised with MultiQC
find NEW -name '*.fastq.gz' -print0 | xargs -0 fastqc -q -t 8 --outdir work/01_fastqc
multiqc -q -f -o "$OUT/multiqc" -n multiqc_raw.html work/01_fastqc

# 1c. Read count / length / GC / mean quality per file
printf 'marker\tsite\tsample\tread\treads\tmean_len\tgc_pct\tmean_q\n' > "$OUT/read_stats.tsv"
for f in NEW/*/*/*.fastq.gz; do
  marker=$(echo "$f" | cut -d/ -f2); site=$(echo "$f" | cut -d/ -f3)
  base=$(basename "$f" .fastq.gz); sample=${base%_R*}; read=${base##*_}
  zcat "$f" | awk -v m="$marker" -v s="$site" -v sm="$sample" -v r="$read" '
    BEGIN { for (i = 33; i < 127; i++) ord[sprintf("%c", i)] = i - 33 }
    NR % 4 == 2 { n++; len += length($0); gc += gsub(/[GCgc]/, "") }
    NR % 4 == 0 { for (i = 1; i <= length($0); i++) q += ord[substr($0, i, 1)]; qn += length($0) }

    Removing the copying labels

    Nearly nine in ten fragments carried both labels exactly where expected — a sign the lab work went well. The primers were identified by reading the data itself, not taken on trust.

    #!/usr/bin/env bash
# Step 2 — Primer removal with Cutadapt.
# Each read must start with its primer (anchored 5'); pairs where either primer is
# missing are discarded. If a read runs through into the opposite primer, that
# (reverse-complemented) primer and everything after it is trimmed too.
#   18S V4 : E572F  CYGCGGTAATTCCAGCTC     / E1009R   AYGGTATCTRWTCRTCTTYG   (Comeau et al. 2011)
#   COI    : mlCOIintF GGWACWGGWTGAACWGTWTAYCCYCC / jgHCO2198 TAIACYTCIGGRTGICCRAARAAYCA (Leray et al. 2013; I -> N)
set -euo pipefail
cd "$(dirname "$0")/.."

OUT=results/02_primer_removal
mkdir -p "$OUT" work/02_trimmed

revcomp() { echo "$1" | rev | tr ACGTRYKMBVDHN TGCAYRMKVBHDN; }

declare -A FWD=( [18S]=CYGCGGTAATTCCAGCTC [COI]=GGWACWGGWTGAACWGTWTAYCCYCC )
declare -A REV=( [18S]=AYGGTATCTRWTCRTCTTYG [COI]=TANACYTCNGGRTGNCCRAARAAYCA )

printf 'marker\tsample\tpairs_in\tpairs_with_both_primers\tpct_kept\n' > "$OUT/cutadapt_summary.tsv"
for m in 18S COI; do
  F=${FWD[$m]}; R=${REV[$m]}
  mkdir -p "work/02_trimmed/$m"
  for r1 in NEW/"$m"/*/*_R1.fastq.gz; do
    s=$(basename "$r1" _R1.fastq.gz); r2=${r1/_R1/_R2}
    cutadapt -j 8 --discard-untrimmed -e 0.15 --minimum-length 50 \
      -g "^${F};required...$(revcomp "$R");optional" -G "^${R};required...$(revcomp "$F");optional" \
      --json "$OUT/${m}_${s}.cutadapt.json" \
      -o "work/02_trimmed/$m/${s}_R1.fastq.gz" -p "work/02_trimmed/$m/${s}_R2.fastq.gz" \
      "$r1" "$r2" > "$OUT/${m}_${s}.cutadapt.log"
    python3 - "$OUT/${m}_${s}.cutadapt.json" "$m" "$s" >> "$OUT/cutadapt_summary.tsv" <<'PY'
import json, sys
j = json.load(open(sys.argv[1]))["read_counts"]
print(f"{sys.argv[2]}\t{sys.argv[3]}\t{j['input']}\t{j['output']}\t{100*j['output']/j['input']:.1f}")
PY
  done
done

# Post-trim length distribution (input to choosing DADA2 truncation lengths)
printf 'marker\tsample\tread\tlength\tcount\n' > "$OUT/trimmed_lengths.tsv"
for f in work/02_trimmed/*/*.fastq.gz; do
  m=$(basename "$(dirname "$f")"); b=$(basename "$f" .fastq.gz)
  zcat "$f" | awk -v m="$m" -v s="${b%_R*}" -v r="${b##*_}" \
    'NR%4==2{c[length($0)]++} END{for(l in c) printf "%s\t%s\t%s\t%d\t%d\n", m, s, r, l, c[l]}' \
    >> "$OUT/trimmed_lengths.tsv"
done

  4. Step 3

    Separating real DNA from typos

    In plain wordsSequencers make occasional typos. If you counted every slightly different spelling as a new organism you would invent thousands of species that don’t exist. This step learns the machine’s typo habits from the data itself, then decides which sequences are real and which are just misspellings of them.

    What survives is a list of ASVs (amplicon sequence variants) — each one an exact, unique DNA signature, roughly “one distinct kind of organism”. The two reads of each fragment are then joined into one full sequence, and chimeras — artificial sequences glued together from two different organisms during copying — are removed.

    Importantly, both lakes were processed together, so the same organism gets the same signature in both lakes and they can be compared fairly.

  5. Step 4

    Weeding out fakes

    In plain wordsThe COI barcode is a recipe for a protein. A genuine recipe reads like a sentence with no “STOP” in the middle. Sequences that contain a stop, or whose length breaks the three-letter rhythm of the code, are broken copies (old “ghost” genes or errors) and are removed. For 18S, sequences far too short or too long to be the real barcode are removed.

    # Step 4 — ASV curation.
#  COI : a real COI ASV is protein-coding. Keep ASVs whose length differs from the 313 bp
#        Leray fragment by whole codons (±10 codons) AND translate with no stop codon
#        under the invertebrate mitochondrial code (NCBI table 5). Others are likely
#        NUMTs / pseudogenes or artefacts.
#  18S : keep ASVs within the expected V4 (E572F–E1009R) length window, 350–480 bp.
suppressPackageStartupMessages({ library(Biostrings); library(data.table); library(ggplot2) })

read_asv <- function(m) fread(file.path("results/03_dada2", m, "asv_table.tsv"))

# ---- COI ----
coi <- read_asv("COI")
dna <- DNAStringSet(coi$sequence)
code5 <- getGeneticCode("5")
stops_in_frame <- sapply(1:3, function(f)
  vcountPattern("*", suppressWarnings(translate(subseq(dna, f), genetic.code = code5,
                                                if.fuzzy.codon = "X"))))
# The coding frame is the one that is stop-free for the most reads
frame <- which.max(colSums((stops_in_frame == 0) * (coi$W1 + coi$W2)))
coi[, `:=`(stops = stops_in_frame[, frame],
           codon_ok = abs(length - 313) %% 3 == 0 & abs(length - 313) <= 30)]
coi[, keep := codon_ok & stops == 0]
coi[, reason := fifelse(keep, "kept", fifelse(!codon_ok, "length not codon-compatible", "stop codon in frame"))]

# ---- 18S ----
s18 <- read_asv("18S")

s18[, reason := fifelse(keep, "kept", "outside 350–480 bp")]

# ---- Write curated tables + summary ----

  7. Step 6

    Putting names to the signatures

    In plain wordsEach signature is still just a string of DNA letters. To name it, we compare it with large public libraries of DNA from organisms that experts have already identified — like matching a fingerprint against a database. A name is accepted only when the match is both confident and close enough: a species name, for example, needs the sequence to be at least 97–99% identical to a known one. If the match is weaker, we only claim a broader group (a family, or just “a rotifer”).

# Step 6 — Taxonomic assignment of curated ASVs with VSEARCH.
#  (a) SINTAX: k-mer classifier with bootstrap confidence per rank (cutoff applied in R).
#  (b) Global alignment to the same reference: % identity of the closest reference sequence,
#      used to decide whether genus/species names are close enough to trust.
# References (downloaded to work/refs, git-ignored):
#   18S : PR2 v5.1.1 SSU, UTAX/SINTAX format
#         https://github.com/pr2database/pr2database/releases/tag/v5.1.1
#   COI : Eukaryote CO1 Reference Set v5.1.0 (Porter & Hajibabaei), SINTAX format
#         https://github.com/terrimporter/CO1Classifier/releases/tag/SINTAX-COI-v5.1.0-ref
set -euo pipefail
cd "$(dirname "$0")/.."

REFS=work/refs
OUT=results/06_taxonomy
mkdir -p "$REFS" "$OUT"

  curl -sL -o "$REFS/pr2_5.1.1_UTAX.fasta.gz" \
    https://github.com/pr2database/pr2database/releases/download/v5.1.1/pr2_version_5.1.1_SSU_UTAX.fasta.gz
fi
if [ ! -s "$REFS/COIv5.1.0_sintax.fasta" ]; then
  curl -sL -o "$REFS/coi.zip" \
    https://github.com/terrimporter/CO1Classifier/releases/download/SINTAX-COI-v5.1.0-ref/SINTAX_COIv5.1.0_ref.zip
  # sequences are distributed in lower case, which VSEARCH treats as masked -> upper-case them
  unzip -p "$REFS/coi.zip" training/sintax.fasta | awk '/^>/ {print; next} {print toupper($0)}' \
    > "$REFS/COIv5.1.0_sintax.fasta" && rm "$REFS/coi.zip"
fi

for m in 18S COI; do
  q=results/04_curation/${m}_asv_seqs_curated.fasta
  # (a) classifier, 100 bootstrap subsamples, both strands
  vsearch --sintax "$q" --db "${DB[$m]}" --strand both --sintax_random --randseed 2026 \
    --tabbedout "$OUT/${m}_sintax.tsv" --threads 16 --quiet
  # (b) closest reference sequence (top hits only; ties kept)
  vsearch --usearch_global "$q" --db "${DB[$m]}" --id 0.70 --strand both \
    --maxaccepts 20 --maxrejects 500 --top_hits_only --output_no_hits \
    --userout "$OUT/${m}_tophit.tsv" --userfields query+target+id+alnlen \
    --threads 16 --quiet
done

    # Step 6 — Turn raw SINTAX + top-hit output into a conservative taxonomy table.
# A rank is accepted only if BOTH
#   (1) SINTAX bootstrap confidence >= 0.80, and
#   (2) the closest reference sequence is similar enough for that rank:
#         COI : species >= 97 %, genus >= 95 %, family >= 90 %, order >= 85 %
#         18S : species >= 99 %, genus >= 97 %, family >= 95 %
# Ranks are accepted top-down; once one fails, all lower ranks are left unassigned.
# PR2 placeholder names (e.g. "Dinophyceae_X", "Enoplea_XX_sp.") are left blank at their
# own rank but do not stop lower ranks (e.g. order "Sphaeropleales_X" -> genus Desmodesmus).
suppressPackageStartupMessages({ library(data.table); library(ggplot2) })

out <- "results/06_taxonomy"
CONF <- 0.80
ranks <- list(
  COI = c(d = "Domain", k = "Kingdom", p = "Phylum", c = "Class", o = "Order",
          f = "Family", g = "Genus", s = "Species"),
  `18S` = c(k = "Domain", d = "Supergroup", p = "Division", c = "Class", o = "Order",
            f = "Family", g = "Genus", s = "Species"))

               `18S` = c(Family = 95, Genus = 97, Species = 99))

parse_sintax <- function(m) {
  s <- fread(file.path(out, sprintf("%s_sintax.tsv", m)), header = FALSE, sep = "\t", quote = "",
             fill = TRUE, col.names = c("asv", "tax", "strand"))[, 1:2]
  r <- ranks[[m]]
  rbindlist(lapply(seq_len(nrow(s)), function(i) {
    parts <- if (is.na(s$tax[i]) || s$tax[i] == "") character() else strsplit(s$tax[i], ",")[[1]]
    d <- data.table(asv = s$asv[i], letter = sub(":.*", "", parts),
                    name = sub("^.:(.*)\\(.*$", "\\1", parts),
                    conf = as.numeric(sub(".*\\((.*)\\)$", "\\1", parts)))
    d[, rank := r[letter]][]
  }), fill = TRUE)
}

summarise_marker <- function(m) {
  r <- unname(ranks[[m]])
  counts <- fread(sprintf("results/04_curation/%s_asv_table_curated.tsv", m))[, .(asv, W1, W2, length)]
  long <- parse_sintax(m)

  hit <- fread(file.path(out, sprintf("%s_tophit.tsv", m)), header = FALSE, sep = "\t", quote = "",
               col.names = c("asv", "target", "identity", "alnlen"))
  hit <- hit[target != "*"][order(asv, -identity)][, .SD[1], by = asv]
  hit[, best_match := gsub("_", " ", sub(".*s:", "", target))]

  # Accept ranks top-down
  long <- merge(long, hit[, .(asv, identity)], by = "asv", all.x = TRUE)
  long[, need := min_id[[m]][rank]][is.na(need), need := 0]
  # PR2 joins division and subdivision ("Chlorophyta-Chlorophyta_X"): keep the division part
  long[, name := sub("-[^-]*_X+$", "", name)]
  long[, placeholder := grepl("(_X+|_sp\\.)$", name) | grepl("^undef_", name)]
  long[, ok := conf >= CONF & !is.na(identity) & identity >= need]
  long[, rank := factor(rank, levels = r)]
  setorder(long, asv, rank)
  long[, ok := cumprod(ok) == 1, by = asv]

  # Placeholders are left blank at their own rank but do not block the ranks below
  wide <- dcast(long[ok == TRUE & !placeholder], asv ~ rank, value.var = "name")
  for (x in r) if (!x %in% names(wide)) wide[, (x) := NA_character_]
  conf_wide <- dcast(long, asv ~ rank, value.var = "conf")
  setnames(conf_wide, setdiff(names(conf_wide), "asv"), paste0("conf_", setdiff(names(conf_wide), "asv")))

  tax <- Reduce(function(a, b) merge(a, b, by = "asv", all.x = TRUE),
                list(counts, wide[, c("asv", r), with = FALSE], conf_wide,
                     hit[, .(asv, identity, best_match)]))
  tax[, deepest := apply(.SD, 1, function(v) { k <- which(!is.na(v)); if (length(k)) r[max(k)] else "Unassigned" }),
      .SDcols = r]
  tax[, label := apply(.SD, 1, function(v) { k <- which(!is.na(v)); if (length(k)) v[max(k)] else "Unassigned" }),
      .SDcols = r]
  tax[, label := gsub("_", " ", label)]
  setorder(tax, -W1)
  fwrite(tax[order(asv)], file.path(out, sprintf("%s_taxonomy.tsv", m)), sep = "\t")
  tax[, marker := m][]
}

  8. Step 7

    Looking up the unknowns in GenBank

    In plain wordsThe COI library used in step 6 is curated and so leaves things out. GenBank, run by the US National Center for Biotechnology Information (NCBI), holds nearly every DNA sequence ever published. We searched it (with a tool called BLAST) for the 40 most abundant COI signatures that step 6 could not name — together about 64% of Chandubi’s and 57% of Deepor’s COI reads.

    Most of them are rotifers that simply aren’t in reference libraries yet. Several match unnamed “rotifer environmental samples” almost exactly (98–100%), sequences found by other studies but never tied to a named species; others are 80–89% similar to known rotifers such as Brachionus, Trichocerca and Anuraeopsis — likely related species that have never been barcoded. Counting these, rotifers make up roughly 62% of Chandubi’s and 66% of Deepor’s COI reads.

    The single most common COI signature is a true unknown. COI_ASV0001 accounts for 15% (Chandubi) and 19% (Deepor) of COI reads, reads cleanly as a protein-coding gene, yet nothing in all of GenBank is more than about 72% identical to it. It belongs to an organism whose DNA has never been sequenced — possibly a new or unstudied local species.

    Script scripts/06b_ncbi_blast.py
    #!/usr/bin/env python3
"""Step 6b helper — BLAST a FASTA file against NCBI core_nt through the NCBI BLAST
URL API (submit, poll, fetch). Writes one tab-separated row per hit:
qseqid, accession, pident, align_len, qcov, evalue, taxid, sciname, kingdom, phylum, class.
Usage: 06b_ncbi_blast.py query.fasta out.tsv [max_hits] [--sensitive]
--sensitive uses blastn (word size 11) instead of megablast, for distant matches.
Appends kingdom, phylum and class of each hit from NCBI Taxonomy."""
import json
import re
import sys
import time
import urllib.parse
import urllib.request

URL = "https://blast.ncbi.nlm.nih.gov/Blast.cgi"
query, out = sys.argv[1], sys.argv[2]
max_hits = int(sys.argv[3]) if len(sys.argv) > 3 else 5
sensitive = "--sensitive" in sys.argv


def call(params, data=False):
    enc = urllib.parse.urlencode(params).encode()
    req = urllib.request.Request(URL, data=enc if data else None,
                                 headers={"User-Agent": "Sahil_Metagenome/1.0 (amplicon taxonomy)"})
    if not data:
        req.full_url = URL + "?" + enc.decode()
    with urllib.request.urlopen(req, timeout=120) as r:
        return r.read()


fasta = open(query).read()
qlen = {m.group(1): len(m.group(2).replace("\n", ""))
        for m in re.finditer(r">(\S+)[^\n]*\n([^>]*)", fasta)}

mode = {"MEGABLAST": "off", "WORD_SIZE": 11} if sensitive else {"MEGABLAST": "on"}
resp = call({"CMD": "Put", "PROGRAM": "blastn", **mode, "DATABASE": "core_nt",
             "QUERY": fasta, "HITLIST_SIZE": max_hits, "EXPECT": "1e-20",
             "EMAIL": "", "TOOL": "Sahil_Metagenome"}, data=True).decode()
rid = re.search(r"RID = (\S+)", resp).group(1)
wait = int(re.search(r"RTOE = (\d+)", resp).group(1))
print(f"RID {rid}, estimated {wait}s", file=sys.stderr)
time.sleep(max(wait, 30))
while True:
    status = call({"CMD": "Get", "RID": rid, "FORMAT_OBJECT": "SearchInfo"}).decode()
    s = re.search(r"Status=(\w+)", status).group(1)
    print(f"status {s}", file=sys.stderr)
    if s == "READY":
        break
    if s in ("FAILED", "UNKNOWN"):
        sys.exit(f"BLAST {s} for RID {rid}")
    time.sleep(60)

raw = call({"CMD": "Get", "RID": rid, "FORMAT_TYPE": "JSON2_S"})
doc = json.loads(raw)
rows = []
for rep in doc["BlastOutput2"]:
    search = rep["report"]["results"]["search"]
    q = search["query_title"].split()[0]
    for hit in search.get("hits", []):
        d = hit["description"][0]
        hsp = hit["hsps"][0]
        rows.append([q, d.get("accession", ""), round(100 * hsp["identity"] / hsp["align_len"], 2),
                     hsp["align_len"], round(100 * (hsp["query_to"] - hsp["query_from"] + 1) / qlen[q], 1),
                     hsp["evalue"], str(d.get("taxid", "")), d.get("sciname", "")])

# Higher taxonomy (phylum, class) for each hit, from NCBI Taxonomy via E-utilities
lineage = {}
taxids = sorted({r[6] for r in rows if r[6]})
for i in range(0, len(taxids), 100):
    xml = urllib.request.urlopen(
        "https://eutils.ncbi.nlm.nih.gov/entrez/eutils/efetch.fcgi?db=taxonomy&id=" + ",".join(taxids[i:i + 100]),
        timeout=120).read().decode()
    for taxon in re.findall(r"<Taxon>\s*<TaxId>(\d+)</TaxId>(.*?)</LineageEx>", xml, re.S):
        tid, body = taxon
        ranks = dict((r, n) for n, r in re.findall(
            r"<ScientificName>([^<]+)</ScientificName>\s*<Rank>([^<]+)</Rank>", body))
        lineage[tid] = (ranks.get("kingdom", ranks.get("superkingdom", "")), ranks.get("phylum", ""),
                        ranks.get("class", ""))
    time.sleep(0.5)

with open(out, "w") as fh:
    for r in rows:
        fh.write("\t".join(map(str, r + list(lineage.get(r[6], ("", "", ""))))) + "\n")
print(f"wrote {out}", file=sys.stderr)

    # Step 6b — Summarise NCBI BLAST results for the most abundant COI ASVs that the
# COI reference library could not place. Best hit = highest % identity × query cover.
# Interpretation: >= 97 % species-level match, >= 90 % same genus/family likely,
# 80-90 % only a distant relative is on record (phylum-level hint only);
# < 80 % nothing informative is on record.
suppressPackageStartupMessages({ library(data.table); library(ggplot2) })

b <- fread(file.path(out, "COI_blast_unknowns.tsv"), header = FALSE, sep = "\t", quote = "",
           col.names = c("asv", "acc", "pident", "length", "qcovs", "evalue", "taxid", "name",
                         "kingdom", "phylum", "class"))
b[, group := fifelse(phylum != "", phylum, fifelse(kingdom != "", kingdom, "unknown"))]
tax <- fread(file.path(out, "COI_taxonomy.tsv"), sep = "\t", quote = "")
ids <- readLines("work/blast_ids.txt")

best <- b[order(asv, -(pident * qcovs))][, .SD[1], by = asv]
res <- merge(data.table(asv = ids), best, by = "asv", all.x = TRUE)
res <- merge(res, tax[, .(asv, W1, W2, library_identity = identity, library_label = label)], by = "asv")
res[, match := fcase(is.na(pident), "no hit in NCBI",
                     pident >= 97 & qcovs >= 90, "species-level match",
                     pident >= 90 & qcovs >= 80, "close relative (genus/family)",
                     default = "distant relative only")]
res[is.na(group), group := "no hit"]
# Below 80 % identity the best hit is not informative even about the phylum
res[!is.na(pident) & pident < 80, group := "no relative >= 80 %"]
setorder(res, -W1)
res[, reads_pct_W1 := round(100 * W1 / sum(tax$W1), 2)][, reads_pct_W2 := round(100 * W2 / sum(tax$W2), 2)]

  9. So far

    What the data tells us

    Two very different microscopic worlds

    By the 18S barcode the lakes share only 142 of 982 signatures. Chandubi’s water is full of green algae, diatoms and protists; Deepor’s is dominated by fungi, desmids, water moulds and small worms.

    Rotifers rule the zooplankton

    About 62% (Chandubi) and 66% (Deepor) of the animal (COI) reads are rotifers, many of them species not yet in any DNA library. Copepods (Mesocyclops and relatives) are present; water fleas were not detected.

    An abundant, unknown organism

    The most common COI signature in both lakes matches nothing on record above ~72% — a candidate for closer study.

    Zooplankton: surprisingly similar — needs checking

    By COI, 266 of 345 signatures appear in both lakes at similar levels, while the algae and protists (18S) differ sharply. Either the zooplankton truly are similar, or DNA crossed between the two samples in the lab. No blank (control) samples were sequenced, so this can’t yet be told apart — a question for Eurofins.

    A caution on comparisons

    There is one water sample per lake. Differences describe these two samples; they cannot yet be tested statistically. Read counts reflect DNA, not the number or weight of organisms.
